# 信息分层写作规则

本文件用于避免把不同来源、不同置信度的信息混写成单一事实。

## 四层信息

### 1. 公开可核验事实

指能够被协会公示、官网原文、正式合同或其他权威公开来源支持的信息，例如：

- 管理人登记编号
- 成立 / 登记时间
- 注册地址 / 办公地址
- 实际控制人
- 公示的员工人数、规模区间、提示类信息

### 2. 管理人口径

指电话会议、路演材料、公开访谈中的表述，例如：

- 当前公司规模
- 核心策略框架
- 近期回撤解释
- 团队分工
- 容量、费率、胜率、修复速度等描述

这类信息必须明确标注为“电话口径”“路演材料口径”或“管理人口径”。

### 3. 差异与冲突

当公开信息与管理人口径不一致时，不做静默裁剪，必须单列，例如：

- 股权安排与公开工商口径不一致
- 规模口径前后不一致
- 员工人数与资格人数不一致
- 费率表述与产品要素表不一致

### 4. 待核实事项

对确有重要性但暂时无法验证的信息，单列进入待核实事项，例如：

- 历史业绩是否属于当前管理人
- 某次异常回撤的真实驱动
- 某项治理变更是否已完成
- 某产品的正式费率、锁定期、开放安排

## 写作动作要求

- 公开事实写在“公开信息核验”
- 管理人口径写在策略、团队、产品等业务章节
- 差异与冲突写进“主要风险点与待核实事项”
- 不允许把“待核实事项”提前写成结论

## 禁止事项

- 把电话中的判断性语言改写成事实性断言
- 把第三方平台简介当作正式证据
- 因为缺少公开证据就用默认值补齐
- 为了让结论更顺滑而删除冲突信息

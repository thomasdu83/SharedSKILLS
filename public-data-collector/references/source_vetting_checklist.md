# 公开源核验清单（首次接入必查）

逐项记录结论，任何一项为"否"需在契约草案中给出替代方案或明确挂起。

## 可得性
- [ ] 数据是否真正免费（无需付费订阅、无隐藏注册墙）？
- [ ] 获取方式：正式 API / 文件下载 / 仅网页展示？网页展示类需评估合规风险。
- [ ] 是否需要 API key？key 是否免费注册即得？

## 数据质量
- [ ] 频率（日/月/事件）与历史深度是否满足需求？
- [ ] 字段口径是否与需求一致（如全收益 vs 价格、名义 vs 实际）？
- [ ] 是否存在 vintage 问题（历史值会被修订/重估）？契约中注明取舍。

## 工程性
- [ ] 有无速率限制、分页机制、超时特征？
- [ ] 国内访问是否需要代理？
- [ ] 空值/缺日的表现形态（如 FRED 的 "."）？

## 合规
- [ ] 再分发/抓取的条款风险是否可接受？
- [ ] 若收费数据的免费替代被使用，是否已向用户声明口径差异？

## 案例（已核验）
- FRED：免费 API，key 免费注册；空值为 "."；每日更新。
- NY Fed ACM：免费 XLSX 下载；模型每月重估，历史值可能微调（接受）。
- FiscalData auctions_query：免费 API 无需 key；事件频率；1979 至今。
- yfinance：免费但非官方；UST 全收益用 IEF/TLT 代理（口径差异已声明）。
- 反例：US 5Y CDS（Markit/ICE 收费）、CPI 调查中位数（彭博/路透收费）——挂起。
